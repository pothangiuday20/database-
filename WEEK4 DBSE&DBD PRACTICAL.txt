    Stories about space

the system should return books such as:

    The Martian
    Dune

even when the search phrase does not exactly occur in the

an embedding model.


====================================================================
IMPORTANT MYSQL NOTE
====================================================================

The original assignment mentions:

    VECTOR(3)

and:

    <->

    <=>

These are associated with PostgreSQL/pgvector-style syntax.

MySQL Workbench cannot execute PostgreSQL pgvector commands.

Therefore, this MySQL practical uses:

    JSON

to store:

    [x, y, z]

and calculates:

    L2 Distance

and:

    Cosine Similarity

using normal MySQL mathematical functions.

Therefore DO NOT execute this in MySQL:

    embedding VECTOR(3)

    embedding <-> '[0.1,0.8,0.2]'

    embedding <=> '[0.1,0.8,0.2]'

Those are not the MySQL solution used in this practical.

PART 10 – L2 DISTANCE
====================================================================

L2 formula:

    Distance =
    SQRT(
        (x1-x2)^2 +
        (y1-y2)^2 +
        (z1-z2)^2
    )


IMPORTANT:

    Smaller distance = more similar.


SQL:

SELECT

    book_id,

    title,

    author,

    genre,

    ROUND(

        SQRT(

            POW(
                CAST(
                    JSON_EXTRACT(embedding, '$[0]')
                    AS DECIMAL(10,6)
                ) - 0.90,
                2
            )

            +

            POW(
                CAST(
                    JSON_EXTRACT(embedding, '$[1]')
                    AS DECIMAL(10,6)
                ) - 0.80,
                2
            )

            +

            POW(
                CAST(
                    JSON_EXTRACT(embedding, '$[2]')
                    AS DECIMAL(10,6)
                ) - 0.20,
                2
            )

        ),

        4

    ) AS l2_distance

FROM Books

WHERE embedding IS NOT NULL

ORDER BY l2_distance ASC

LIMIT 3;


EXPECTED OUTPUT:

+---------+------------------+------------------+------------------+-------------+
| book_id | title            | author           | genre            | l2_distance |
+---------+------------------+------------------+------------------+-------------+
| 1       | The Martian      | Andy Weir        | Science Fiction  | 0.0000      |
| 8       | Enders Game      | Orson Scott Card | Science Fiction  | 0.0860      |
| 2       | Dune             | Frank Herbert    | Science Fiction  | 0.0866      |
+---------+------------------+------------------+------------------+-------------+


CONCLUSION:

The 3 closest books are:

    1. The Martian
    2. Enders Game
    3. Dune

PART 11 – COSINE SIMILARITY
====================================================================

Cosine similarity measures the angle between two vectors.

Formula:

             A . B
    -----------------------
    |A| x |B|


Higher value = more similar.


SQL:

SELECT

    book_id,

    title,

    author,

    genre,

    ROUND(

        (

            CAST(
                JSON_EXTRACT(embedding, '$[0]')
                AS DECIMAL(10,6)
            ) * 0.90

            +

            CAST(
                JSON_EXTRACT(embedding, '$[1]')
                AS DECIMAL(10,6)
            ) * 0.80

            +

            CAST(
                JSON_EXTRACT(embedding, '$[2]')
                AS DECIMAL(10,6)
            ) * 0.20

        )

        /

        (

            SQRT(

                POW(
                    CAST(
                        JSON_EXTRACT(embedding, '$[0]')
                        AS DECIMAL(10,6)
                    ),
                    2
                )

                +

                POW(
                    CAST(
                        JSON_EXTRACT(embedding, '$[1]')
                        AS DECIMAL(10,6)
                    ),
                    2
                )

                +

                POW(
                    CAST(
                        JSON_EXTRACT(embedding, '$[2]')
                        AS DECIMAL(10,6)
                    ),
                    2
                )

            )

            *

            SQRT(

                POW(0.90, 2)

                +

                POW(0.80, 2)

                +

                POW(0.20, 2)

            )

        ),

        4

    ) AS cosine_similarity

FROM Books

WHERE embedding IS NOT NULL

ORDER BY cosine_similarity DESC

LIMIT 3;


EXPECTED OUTPUT:

+---------+------------------+------------------+------------------+-------------------+
| book_id | title            | author           | genre            | cosine_similarity |
+---------+------------------+------------------+------------------+-------------------+
| 1       | The Martian      | Andy Weir        | Science Fiction  | 1.0000            |
| 8       | Enders Game      | Orson Scott Card | Science Fiction  | 0.9980            |
| 2       | Dune             | Frank Herbert    | Science Fiction  | 0.9976            |
+---------+------------------+------------------+------------------+-------------------+


CONCLUSION:

Higher cosine similarity means greater similarity.

const express = require("express");

const mysql = require("mysql2/promise");

const app = express();

const PORT = 3000;

app.use(express.json());


const pool = mysql.createPool({

    host: "localhost",

    user: "root",

    password: "YOUR_MYSQL_PASSWORD",

    database: "bookflow_db",

    waitForConnections: true,

    connectionLimit: 10,

    queueLimit: 0

});


app.get("/", (req, res) => {

    res.json({

        message: "BookFlow Intelligent Catalog API",

        status: "Running",

        endpoints: {

            search: "GET /v1/books/search",

            createBook: "POST /v1/books"

        }

});


app.get("/v1/books/search", async (req, res) => {

    try {

        const q = req.query.q;

        const limit = parseInt(req.query.limit || "10");


        if (!q || q.trim() === "") {

            return res.status(400).json({

                error: {

                    code: "INVALID_QUERY",

                    message:
                    "Query parameter q is required."

                }

            });

        }


        if (
            isNaN(limit) ||
            limit < 1 ||
            limit > 50
        ) {

            return res.status(400).json({

                error: {

                    code: "INVALID_LIMIT",

                    message:
                    "limit must be between 1 and 50."

                }

            });

        }


        /*
          MOCK QUERY VECTOR

          Stories about space

          [0.90, 0.80, 0.20]
        */

        const x = 0.90;

        const y = 0.80;

        const z = 0.20;


        const sql = `

        SELECT

            book_id,

            title,

            author,

            genre,

            description,

            published_year,

            ROUND(

                (

                    CAST(
                        JSON_EXTRACT(
                            embedding,
                            '$[0]'
                        )
                        AS DECIMAL(10,6)
                    ) * ?

                    +

                    CAST(
                        JSON_EXTRACT(
                            embedding,
                            '$[1]'
                        )
                        AS DECIMAL(10,6)
                    ) * ?

                    +

                    CAST(
                        JSON_EXTRACT(
                            embedding,
                            '$[2]'
                        )
                        AS DECIMAL(10,6)
                    ) * ?

                )

                /

                (

                    SQRT(

                        POW(
                            CAST(
                                JSON_EXTRACT(
                                    embedding,
                                    '$[0]'
                                )
                                AS DECIMAL(10,6)
                            ),
                            2
                        )

                        +

                        POW(
                            CAST(
                                JSON_EXTRACT(
                                    embedding,
                                    '$[1]'
                                )
                                AS DECIMAL(10,6)
                            ),
                            2
                        )

                        +

                        POW(
                            CAST(
                                JSON_EXTRACT(
                                    embedding,
                                    '$[2]'
                                )
                                AS DECIMAL(10,6)
                            ),
                            2
                        )

                    )

                    *

                    SQRT(

                        POW(?, 2)

                        +

                        POW(?, 2)

                        +

                        POW(?, 2)

                    )

                ),

                4

            ) AS similarity

        FROM Books

        WHERE embedding IS NOT NULL

        ORDER BY similarity DESC

        LIMIT ?

        `;


        const [rows] = await pool.execute(

            sql,

            [
                x,
                y,
                z,
                x,
                y,
                z,
                limit
            ]

        );


        res.status(200).json({

            query: q,

            count: rows.length,

            results: rows

        });

    }

    catch (error) {

        console.error(error);

        res.status(500).json({

            error: {

                code:
                "INTERNAL_SERVER_ERROR",

                message:
                "Unable to perform book search."

            }

        });

    }

});


app.post("/v1/books", async (req, res) => {

    try {

        const {

            title,

            author,

            genre,

            description,

            published_year,

            embedding

        } = req.body;


        if (!title || !author || !genre) {

            return res.status(400).json({

                error: {

                    code:
                    "INVALID_BOOK",

                    message:
                    "title, author and genre are required."

                }

            });

        }


        const sql = `

        INSERT INTO Books

        (

            title,

            author,

            genre,

            description,

            published_year,

            embedding

        )

        VALUES (?, ?, ?, ?, ?, ?)

        `;


        const [result] = await pool.execute(

            sql,

            [

                title,

                author,

                genre,

                description || null,

                published_year || null,

                embedding
                    ? JSON.stringify(embedding)
                    : null

            ]

        );


        res.status(201).json({

            message:
            "Book created successfully",

            book: {

                book_id:
                result.insertId,

                title,

                author,

                genre,

                description:
                description || null,

                published_year:
                published_year || null,

                embedding:
                embedding || null

            }

        });

    }

    catch (error) {

        console.error(error);

        res.status(500).json({

            error: {

                code:
                "INTERNAL_SERVER_ERROR",

                message:
                "Unable to create book."

            }

        });

    }

});

PART 22 – VERIFY REST CONSTRAINTS
====================================================================

REQUIREMENT 1 – STATELESSNESS
------------------------------

The API is stateless.

The server does not store a user's previous search session.

Each request contains the information required to process it.

Example:

    GET /v1/books/search?q=Stories%20about%20space&limit=3


The request can be processed independently.


--------------------------------------------------------------------
REQUIREMENT 2 – GET
--------------------------------------------------------------------

GET is used for retrieving/searching books.

Correct:

    GET /v1/books/search


GET does not create a book.


--------------------------------------------------------------------
REQUIREMENT 3 – POST
--------------------------------------------------------------------

POST is used for creating a new book.

Correct:

    POST /v1/books


POST creates a new database record.


--------------------------------------------------------------------
REQUIREMENT 4 – HTTP STATUS CODES
--------------------------------------------------------------------

Successful search:

    200 OK


Successful creation:

    201 Created


Invalid request:

    400 Bad Request


Server error:

    500 Internal Server Error
